# 导览

## 常见平台

- [中国机械工业联合会](https://www.mei.net.cn/)：机械工业唯一的全国性综合性行业协会。2001年3月注册成立，是在我国工业管理体制改革中由机械工业全国性协会、地区性协会、具有重要影响的企事业单位、科研院所和大中专院校等自愿组成的社会团体。
- [中国机械社区](http://www.cmiw.cn/)：成立于2005年，综合性专业技术社区。以“技术研讨”和“行业分析”为核心。
- [三维网技术论坛](https://www.gongyeshe.cn/)：成立于2006年，国内制造业中最大的技术交流论坛之一。以三维机械设计和制造为主题，内容极细。
- [工业汇](https://bbs.gongyehub.cn/)：主打“实名、纯净、干货”。平台坚守永久免费、全员实名、无商业广告，内容聚焦一线实操技术。
