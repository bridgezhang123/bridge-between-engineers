# Cookie 政策

## 1. 我们使用 Cookie 的目的

为了让本网站更稳定、更易用，并持续改进内容与访问体验，我们会在必要范围内使用 Cookie。

Cookie 主要用于：

- 记住用户的偏好设置，例如页面主题、语言或展示方式
- 提高站点导航效率，减少重复操作
- 统计站点访问量和页面使用情况，以便评估内容质量与访问结构
- 了解内容受欢迎程度，并帮助优化文档结构和阅读体验

我们不会为了广告投放或市场营销而滥用 Cookie，也不会在未告知的情况下收集敏感个人信息。

## 2. Cookie 的类型

### 2.1 必要 Cookie

这些 Cookie 对站点正常运行至关重要，通常用于：

- 确保网页能够正常加载和显示
- 记住用户在站点中的基础设置
- 确保安全和站内功能可用

如果不启用这些 Cookie，部分站点功能可能无法正常工作。

### 2.2 分析 Cookie

开启匿名访问统计后，本站会累计各页面的访问次数，帮助了解哪些内容更受关注。统计只按页面记录次数，不记录个人浏览路径或停留时长。

不启用该选项，网站也可以正常浏览。

## 3. 用户控制权

访问本站时，您可以在 Cookie 同意弹窗中选择：

- 仅使用必要设置
- 允许匿名访问统计
- 打开设置选项，自行选择是否允许匿名访问统计

匿名访问统计默认关闭；只有选择允许后才会启用。

如果您已经做出选择，浏览器中会保存对应的设置；之后访问本站时，将按您的偏好处理 Cookie。

如需调整设置，通常可以：

- 在浏览器中清除相关 Cookie
- 或重新访问站点时重新选择

## 4. 访问与第三方

本站使用自有页面访问量统计。页面底部评论功能由 Giscus 提供，并使用 GitHub Discussions 保存评论。加载或使用评论功能时，浏览器会连接 Giscus 和 GitHub；发表评论需要使用 GitHub 账号授权。评论内容公开显示，相关数据由 Giscus 和 GitHub 按其各自的隐私政策处理。

评论内容不存储在本站的页面访问量数据库中。若后续接入其他第三方服务，我们会在相应功能中进行说明。

## 5. 个人信息保护

我们承诺：

- 仅在必要范围内使用 Cookie
- 尽量以匿名、汇总的方式使用分析数据
- 不将 Cookie 数据用于不当的个人识别或敏感信息归档

如果您希望进一步了解站点的内容与隐私实践，欢迎通过邮件联系：`contact@bridgezhang.com`

如果您对本政策或站点数据处理方式有疑问，可以通过站点页脚或联系信息进行沟通。
